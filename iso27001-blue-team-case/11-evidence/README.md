# Índice de evidências

Este repositório não contém evidências reais de produção.

| Evidência | Fonte esperada | Sanitização |
|---|---|---|
| Aprovação de escopo/política | SGSI | remover dados pessoais desnecessários |
| Risk register aprovado | GRC | remover informações sensíveis |
| SoA | SGSI | revisar referências internas |
| Logs de IdP | SIEM/IdP | anonimizar usuários e IPs quando possível |
| Testes de detecção | SIEM/EDR | remover dados de terceiros |
| Restore test | Backup | remover segredos e dados reais |
| Auditoria interna | GRC/Auditor | revisar PII e confidencialidade |

Para cada evidência, registrar ID, data/hora, fonte, método de coleta, hash quando aplicável, owner e retenção.
