# Segurança do repositório

Este diretório é educacional e não opera serviço real.

- Não publique segredos, credenciais ou dados pessoais.
- Não inclua logs de terceiros sem autorização.
- Testes ofensivos somente em ativos próprios/laboratório autorizado.
- Se uma credencial for publicada por engano, revogue-a imediatamente.
