# Blue Team Investigations

A portfolio repository for defensive cybersecurity exercises, security operations investigations, and information-security management case studies.

## Projects

### [ISO/IEC 27001:2022 + Blue Team Case](./iso27001-blue-team-case/)

A documented fictional SaaS-company case study connecting an Information Security Management System (ISMS) with defensive security operations. Topics include governance, risk management, control selection, logging, detection, incident response, internal audit, metrics, and evidence management.

**Important:** the organization, assets, risks, incidents, metrics, and outcomes in this case study are fictional. It is an educational portfolio exercise, not a real-world audit, certification, or implementation.

### [SOC Phishing Investigation Lab](./soc-phishing-lab/)

A Tier 1 SOC-style investigation exercise based on supplied event logs. The exercise asks the analyst to identify phishing indicators, trace endpoint activity, extract indicators of compromise (IOCs), and assess the endpoint protection response.

## Scope

The repository focuses on defensive analysis, documentation, incident investigation, and security governance. Any attack-related artifacts are intended for controlled, educational analysis.

## Responsible use

Use the labs only in systems and environments you own or are explicitly authorized to investigate. Do not use the material to access, disrupt, or compromise third-party systems.
